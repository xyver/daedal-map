How this map works

Use this map to test road closures, one-way roads, shelters, and travel times around Lake County.

  1. Edit roads. Click a road segment to cycle it from open, to either one-way direction, to closed, then back to open. Changed segments show a matching arrow or X.
  2. Adjust shelters. Click empty map space near a road to add a snapped custom shelter. Click any shelter pin to inspect it, close/reopen it, or delete a custom shelter.
  3. Set a start point. Click an empty location near a road and choose Set start point. The house snaps to the graph so routes use the road network rather than straight-line distance.
  4. Calculate routes. Choose a travel-time limit, then calculate. The sidebar lists reachable shelters; select one to highlight its route.
  5. Save your work. Save a scenario to keep your road edits, shelter changes, and start point. Load it later to continue where you left off.

Map area

The map focuses on Lake County. Nearby roads and shelters are included so routes can cross a county line when that is the practical way to travel.
