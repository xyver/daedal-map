DaedalMap Launcher - Windows

Unzip the entire archive into a writable folder before starting
DaedalMapLauncher.exe. Keep the _internal folder and uv.exe beside the
executable. The launcher creates its shared data catalog on first boot under:

  launcher-data\runtime\data\catalog.json

Open Programs to download a listed tool. You can also drag a published program
ZIP from the downloads page onto the Programs tab, or use Import ZIP. The ZIP
must match a release in the live or cached storefront catalog. Program source
is installed under launcher-data\programs. Local Custom mode makes editable
copies in launcher-data\custom. Settings lets you
choose another library location if you want the data on another drive.
On first program install, the launcher downloads the software needed to run
it. Later tools share those installed dependencies.

Mapping appears when its download is available. You can use MCP tools and
downloaded data without Mapping.
