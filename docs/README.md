# Public Documentation

Start with the root [README](../README.md) to run the project.

Then use [CONTEXT.md](CONTEXT.md) as the technical router for code,
data, modes, packs, APIs, maps, development, and self-hosting.

For editable launcher programs and local catalogs, see the
[custom work requirements](custom-work/README.md).

The public documentation is written for researchers, self-hosters, integrators,
and contributors. Private business systems, operator runbooks, release control,
and production collector details are intentionally outside this repository.
